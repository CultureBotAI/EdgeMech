# Scientific applicability before retrieval — fresh recanary

PR76, 2026-11-13. Rules use only the original transform, predicate and object identifier. They run in table order; the first match wins. Object prefixes are literal CURIE namespaces or explicit source-field stems, with `*` meaning any value. Comma-separated entries mean OR. No name, inherited verdict, paper result or search success changes applicability.

Source fidelity applies to all 50 edges. Scientific retrieval runs only for APPLICABLE rows. NOT_APPLICABLE rows remain separate and are excluded from scientific support-rate denominators. Applicable claims with unresolved names, units or polarity may later be NOT_ASSESSABLE; applicability alone does not approve a claim. Source-field metadata-only and unmapped Other classes are explicitly excluded before the broader biological-field rule.
